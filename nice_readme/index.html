Projet IA – Guide de démarrage

Vue d’ensemble

Ce dépôt offre une configuration Dockerisée pour LiteLLM, un proxy Open‑AI‑compatible, ainsi qu’une intégration avec Claude Code. Vous pourrez rapidement lancer un proxy, choisir un modèle et exécuter Claude depuis votre terminal.

Configuration du proxy

Copiez le fichier d’exemple et renseignez vos clés :

cp .env.example .env
# Remplir NVIDIA_API_KEY et LITELLM_MASTER_KEY dans .env

Lancer le proxy

./start-proxy.sh

Le serveur écoute sur 127.0.0.1:4000 uniquement.

Utiliser Claude Code

Dans un terminal dédié, chargez le proxy, puis lancez Claude :

source ./claude-proxy-env.sh
claude

Gestion des modèles

Les modèles se déclarent dans litellm_config.yaml. Vous pouvez les lister et choisir un modèle avec : 

claude-model          # liste
claude-model    # sélection

La sélection modifie les variables ANTHROPIC_MODEL et ses variantes.
Le model_name doit être présent sur litellm_config.yaml.

Arrêt du proxy

docker compose down
